# Project Rules

## Git Auto-Push
Whenever you finish making file changes in this repository:
1. Stage the modified files (`git add`).
2. Create a commit with a descriptive message (`git commit -m "..."`).
3. Push the commit to GitHub (`git push origin main`).

*(Note: Use `/Library/Developer/CommandLineTools/usr/bin/git` on this machine, and use `BypassSandbox: true` for `git push` to allow network access).*
